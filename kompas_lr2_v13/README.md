# ЛР №2 «Построение чертежа типовой детали в КОМПАС-3D» — вариант 13

- `LR2_variant13.dxf` — чертёж (А4 книжный, масштаб 1:1; главный вид с вертикальной осью, под ним вид сверху). Открыть в КОМПАС-3D: «Файл → Открыть»,
  тип файла «DXF», затем «Файл → Сохранить как…» → `.cdw`.
- `LR2_variant13.pdf`, `LR2_variant13.png` — превью / печать.
- `build_v13.py` — скрипт, генерирующий DXF (`pip install ezdxf`).

Деталь — фланец 60×80 со скосами 45° и двумя пазами R5 (межцентровое 70), цилиндр Ø55×40 с фаской 3×45°,
сквозное квадратное отверстие □15 на глубину 30, резьба М30 длиной 20 в расточке глубиной 25 (фаска 2×45°),
2 резьбовых отверстия на расстоянии 40 глубиной 20 с фаской 1,5×45°.
Размер резьбы этих отверстий на исходном чертеже не указан — нарисованы как М10.
