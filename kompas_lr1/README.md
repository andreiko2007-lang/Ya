# ЛР №1 «Построение примитивов в системе КОМПАС 3D»

Задание одно для всех (вариантов в методичке нет), образец — рис. 2.7.

- `LR1_list1.dxf` — лист 1 (А4): отрезки AB, AC ⟂ AB, BM ∥ AC со скруглением R10 и фаской 4×45°,
  концентрические окружности, сопряжение окружностей R20 и R10 (межцентровое 30) касательной и дугой R5.
- `LR1_list2.dxf` — лист 2 (А4): типовая деталь (втулка Ø60/Ø50, отверстие Ø30, длина 40, фаска 2,5×45°),
  половина вида + половина разреза, масштаб 2:1 (размеры — в натуральную величину).
- `LR1_Vasilieva.pdf` — оба листа одним PDF; `LR1_list*.png` — превью.
- `build_lr1.py` — генератор: `python build_lr1.py 1` и `python build_lr1.py 2` (нужен ezdxf).

Открыть в КОМПАС-3D: «Файл → Открыть», тип файла «DXF», затем «Сохранить как…» → `.cdw`.
