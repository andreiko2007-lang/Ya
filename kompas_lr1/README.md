# ЛР №1 «Построение примитивов в системе КОМПАС 3D»

Задание одно для всех (вариантов в методичке нет), образец — рис. 2.7. Всё размещено на одном листе А4.

- `LR1_Vasilieva.dxf` — чертёж: сверху отрезки AB, AC ⟂ AB, BM ∥ AC со скруглением R10 и фаской 4×45°,
  сопряжение окружностей R20 и R10 (межцентровое 30) касательной и дугой R5, концентрические окружности;
  ниже — типовая деталь (втулка Ø60/Ø50, отверстие Ø30, длина 40, фаска 2,5×45°) в масштабе 2:1
  (размеры — в натуральную величину).
- `LR1_Vasilieva.pdf`, `LR1_Vasilieva.png` — превью / печать.
- `build_lr1.py` — генератор (`python build_lr1.py`, нужен ezdxf).

Открыть в КОМПАС-3D: «Файл → Открыть», тип файла «DXF», затем «Сохранить как…» → `.cdw`.
