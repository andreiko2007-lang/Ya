# ЛР №2 «Построение чертежа типовой детали в КОМПАС-3D» — вариант 5

- `LR2_variant5.dxf` — чертёж (А4 книжный, масштаб 1:1; главный вид с вертикальной осью, под ним вид сверху).
  Открыть в КОМПАС-3D: «Файл → Открыть», тип файла «DXF», затем «Сохранить как…» → `.cdw`.
- `LR2_variant5.pdf`, `LR2_variant5.png` — превью / печать.
- `build_v5.py` — скрипт, генерирующий DXF (`pip install ezdxf`).

Деталь — втулка: головка с резьбой М70 длиной 30 (фаски 2×45° и 1,6×45°), расточка Ø56 глубиной 15,
хвостовик Ø50 с лысками под размер 40, общая длина 87,84; на торце 2 отв. Ø6 (на Ø40) глубиной 20
с фаской 1,5×45°; в головке 2 отв. Ø10.
Не указаны на исходном чертеже и сняты по масштабу: сквозное отверстие ≈Ø20, расточка на торце ≈Ø30
глубиной 20, положение отверстий Ø10 (на окружности Ø56).
