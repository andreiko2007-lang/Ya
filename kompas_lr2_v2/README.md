# ЛР №2 «Построение чертежа типовой детали в КОМПАС-3D» — вариант 2

- `LR2_variant2.dxf` — чертёж (А4 книжный, масштаб 1:1; главный вид с вертикальной осью, под ним вид сверху).
  Открыть в КОМПАС-3D: «Файл → Открыть», тип файла «DXF», затем «Сохранить как…» → `.cdw`.
- `LR2_variant2.pdf`, `LR2_variant2.png` — превью / печать.
- `build_v2.py` — скрипт, генерирующий DXF (`pip install ezdxf`).

Деталь — корпус квадратного сечения □65, длина 70, проточка Ø45 (16…25), пазы 20×7,5 длиной 30, фаски 2,5×45°;
резьба М26 с внутренней проточкой шириной 3 (на 10 от торца), фаска 2×45°, квадратное отверстие □28 (под 45°)
глубиной 20, 4 сквозных отв. Ø6 в левой части.
Не указаны на исходном чертеже и сняты по масштабу: окружность центров отв. Ø6 (Ø55), Ø внутренней проточки (≈Ø27,5),
шаг резьбы (М26×1,5).
