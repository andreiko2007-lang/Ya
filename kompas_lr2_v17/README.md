# ЛР №2 «Построение чертежа типовой детали в КОМПАС-3D» — вариант 17

- `LR2_variant17.dxf` — чертёж (А4 книжный, масштаб 1:1; главный вид с вертикальной осью, под ним вид сверху).
  Открыть в КОМПАС-3D: «Файл → Открыть», тип файла «DXF», затем «Сохранить как…» → `.cdw`.
- `LR2_variant17.pdf`, `LR2_variant17.png` — превью / печать.
- `build_v17.py` — скрипт, генерирующий DXF (`pip install ezdxf`).

Деталь — втулка Ø50 с квадратным фланцем □80 (R10) толщиной 15, общая длина 60; сквозное отверстие Ø14
с фасками 2×45°, расточка Ø30 во фланце, 4 отв. М6 на Ø65, 4 отв. Ø10 глубиной 15 в торце, фаски 1,5×45° (5 фасок).
Окружность центров отверстий Ø10 на исходном чертеже не указана — принята Ø35 (снята с разреза).
