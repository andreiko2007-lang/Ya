# ЛР №2 «Построение чертежа типовой детали в КОМПАС-3D» — вариант 19

- `LR2_variant19.dxf` — чертёж (А4 книжный, масштаб 1:1; главный вид с вертикальной осью, под ним вид сверху). Открыть в КОМПАС-3D: «Файл → Открыть», тип файла
  «DXF», затем «Файл → Сохранить как…» → `.cdw`.
- `LR2_variant19.png` — превью.
- `build_v19.py` — скрипт, генерирующий DXF (`pip install ezdxf`).

Деталь — втулка фланцевая: Ø60×60, две проушины R6 толщиной 12 с отверстиями Ø10 (межосевое 80),
сквозное отверстие Ø14, канавка Ø22 шириной 7, квадратное отверстие □35 (R4) глубиной 30,
паз 8×10 на торце, 2 резьбовых отверстия M12 (резьба 12, сверление 15), фаски 2,5×45° и 2×45°.
Главный вид — соединение половины вида и половины разреза; вид справа расположен слева от главного.
